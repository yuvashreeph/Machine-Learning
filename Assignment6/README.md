# Spam Classification with Dimensionality Reduction (A/B Experiment)

This repository contains the code and report for a machine learning project that compares the performance of ten different classification models on a spam detection task. The project conducts an A/B experiment to evaluate the impact of Principal Component Analysis (PCA) on model accuracy and generalization.

## 📖 Project Overview

The primary goal of this experiment is to evaluate the practical differences in performance between models trained on high-dimensional vs. dimensionally-reduced data for spam classification:

  - **Scenario A**: Models are trained on the **original, full feature set**.
  - **Scenario B**: Models are trained on a **reduced feature set** generated by Principal Component Analysis (PCA).

The experiment systematically identifies the most effective classification algorithm for this task and analyzes how each model's performance is affected by the application of PCA, providing insights into the trade-offs between feature complexity and predictive power.

## 📊 Dataset

The project uses the **Spambase Data Set** from the UCI Machine Learning Repository. It consists of 4601 emails, each represented by 57 continuous features and a target class indicating whether the email is spam (1) or not (0). Features include the frequency of specific words (e.g., "make", "free") and special characters (e.g., "$", "\!").

## ⚙️ Methodology

The project follows a standard machine learning pipeline:

1.  **Data Loading and Preprocessing**: The Spambase dataset is loaded, and missing values are imputed with the median. Outliers are identified and removed using the Z-score method.
2.  **Feature Scaling**: All features are standardized using `StandardScaler` to ensure a mean of 0 and a standard deviation of 1.
3.  **Train/Test Split**: The cleaned data is split into training (80%) and testing (20%) sets using stratification.
4.  **A/B Model Training**:
      - All ten models are trained on the original scaled training data.
      - PCA is applied to the training data, and all ten models are trained again on the reduced-dimension data.
5.  **Model Evaluation**: Models from both scenarios are evaluated on the held-out test set based on **Accuracy, Precision, Recall, F1-Score, and AUC**.

## 🤖 Models Implemented

A comprehensive suite of ten different classification algorithms was trained and evaluated:

  - Logistic Regression
  - K-Nearest Neighbors (KNN)
  - Gaussian Naive Bayes
  - Decision Tree
  - Support Vector Machine (SVM)
  - Random Forest
  - AdaBoost
  - Gradient Boosting
  - **XGBoost** (eXtreme Gradient Boosting)
  - Stacked Ensemble Classifier

## 🏆 Results

The **XGBoost** classifier significantly outperformed all other models, demonstrating the power of gradient boosting for this classification task. The experiment also revealed that while PCA can sometimes harm the performance of complex models, it can dramatically improve simpler models that have strong assumptions about feature independence.

The best-performing model was **XGBoost trained on the original feature set**.

| Model | Accuracy | Precision | Recall | F1-Score |
| :--- | :--- | :--- | :--- | :--- |
| **XGBoost** | **0.9405** | **0.9328** | **0.9161** | **0.9244** |
| Gradient Boosting | 0.9314 | 0.9262 | 0.8968 | 0.9113 |
| Random Forest | 0.9245 | 0.9103 | 0.8968 | 0.9035 |
| Naive Bayes | 0.7254 | 0.6277 | 0.7516 | 0.6841 |

*Note: The performance of Naive Bayes **improved from 74% to 84% accuracy** (in cross-validation) after applying PCA.*
